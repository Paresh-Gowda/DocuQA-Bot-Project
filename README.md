# 🤖 DocuQA

DocuQA is an AI-powered document assistant that allows users to upload PDF documents, generate summaries, and ask questions about their documents. The project is designed to make it easier to understand and interact with information from large documents.

The **frontend has been completed using React**, including the navigation bar, PDF upload interface, summary section, chat interface, styling, and footer. The frontend provides the complete user interface for interacting with the application.

The next phase is to build the **backend using Python and FastAPI**. We will then integrate PDF processing, LangChain, RAG, embeddings, vector storage, and an LLM to make document summarization and question answering functional.
